# Project memory

## Product intent & audience

- Cloning https://roofenclaves.in/ as a Vite + React + Tailwind app.
- Real-estate property listings portal for Indian metros (Hyderabad, Bangalore, Chennai, Mumbai, Pune).
- Audience: prospective property buyers/renters browsing projects by city.

## Brand personality & voice

- Professional, trustworthy real-estate portal tone.
- Category-style listings language with city groupings and quick actions.

## Visual design & UX direction

- Single landing page layout inferred from the source site.
- Sections built: top navigation, hero banner with four quick-link buttons, city tabs with project cards, About, Services, Why Us, contact form, footer.
- Icons via lucide-react; components imported through `@/` alias.
- Images are placeholders pending real assets.

## Decisions, constraints & rationale

- Home page only so far; other site pages not yet implemented.
- Project text/listings and contact details are self-written placeholders to be replaced with real data.
- Careers nav item points to a section that does not exist yet.
- Build passes; browser preview not yet verified.
- No extra UI/icon packages installed beyond the template defaults.
